GeoParquet 2.0 conformance checker

Runs the abstract tests of the OGC GeoParquet 2.0 draft (opengeospatial/geoparquet#304) in your browser. Files never leave your machine; URLs are read with range requests from the browser, so the server must allow cross-origin reads (public S3 buckets with CORS, GitHub raw, source.coop do).

Drop a .parquet file here, or click to choose one
Same code as the command-line checker in geoparquet-testing#6, compiled to WebAssembly. Verdicts follow the abstract-test text; a sampled URL run is not a conformance pass.
